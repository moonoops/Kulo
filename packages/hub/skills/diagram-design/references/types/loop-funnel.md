# Loop / Flywheel, Funnel / Pyramid & Venn

## Reinforcing Loop / Flywheel
- **Geometry**: 3–6 nodes placed evenly around a circular perimeter (`ViewBox 0 0 680 420`), connected by clean clockwise curved arcs (`A` or `Q` commands, marked `data-radial="true"`).
- **Accumulating hub**: Place the compounding outcome/state cleanly in the center (`fill="var(--d-accent-tint)" stroke="var(--d-accent)"`) with concise 2-line label.

## Funnel / Pyramid
- **Funnel (conversion drop-off)**: 3–5 centered horizontal trapezoids narrowing downward, widths proportional to remaining ratio, with stage name inside and exact count + drop-off `%` aligned cleanly in a right-hand margin column.
- **Pyramid (ranked hierarchy)**: 3–4 stacked bands widening downward; keep labels concise inside bands or aligned horizontally with leader hairlines to the right so text never cramps the top apex.

## Venn Diagram (2–3 Sets Max)
- Overlapping circles with low-opacity fills (`opacity="0.10–0.16"`) and `1.25px` strokes; place crisp labels strictly inside each distinct non-overlapping & intersection region with generous breathing room.
